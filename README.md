# Daymark — To-Do List

A responsive, Fiverr-green-inspired task manager built with plain HTML, CSS, and JavaScript.

## Run it

1. Extract `fiverr_inspired_todo.zip` if you downloaded the ZIP.
2. Open the `fiverr_inspired_todo` folder.
3. Double-click **`index.html`** to launch it in your browser.

No Node.js, Python, database, build step, or package installation is required. An internet connection is only needed to load the optional Inter font; the app itself works offline using a system sans-serif fallback.

## Features

- Add, edit, and delete tasks with confirmation before deletion
- Mark tasks complete or active
- Due dates, overdue labels, priorities, notes, and categories
- Search tasks and filter by all, to-do, overdue, today, upcoming, completed, or category
- Sort by due date, priority, recently added, or name
- Live statistics and completion progress
- Local Storage persistence in the browser
- Light/dark theme preference saved locally
- Responsive desktop, tablet, and mobile layouts
- Keyboard focus styles, accessible labels, reduced-motion support, and toast feedback

## Data and privacy

Tasks and categories are stored in the current browser's Local Storage on this device. They are not sent to a server. Clearing the browser's site data may remove saved tasks. If you open the app in a different browser or device, the data will not automatically follow.

## Troubleshooting

If tasks do not appear after reopening, use the same browser and avoid private/incognito mode. If browser storage is disabled, the app may not be able to save your tasks.
